# Attendance CRM
A browser-based attendance CRM demo with:
- Employee ID and name
- Selfie capture using device camera
- Current GPS location with accuracy
- Date/time capture
- Attendance records and dashboard
- Search/filter
- Google Maps location link
- Local browser storage for demo purposes

## How to run
Open `index.html` in a modern browser. Camera and GPS permissions are required.

## Important
This is a front-end demo/prototype. For a production company system, connect it to a backend/database, authentication, HTTPS, secure image storage, role-based access, and an appropriate privacy/consent policy.
